# Sotto for Android

Narrates documents entirely on your device with Kokoro-82M. Two flavors:
`local` (no INTERNET permission - the manifest is the privacy claim) and
`sync` (opt-in library sync with your own Sotto server).

Sibling of the Sotto web service: https://github.com/JacobStephens2/sotto

Status: **Phase 0 - SPIKE-001** (on-device synthesis feasibility; see
`docs/03-roadmap.md` and `docs/_state.md` for the gate and measurements).

All planning documents live in `docs/` - start at `docs/README.md`;
`docs/constitution.md` is binding.
